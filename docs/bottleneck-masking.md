# 锁定已知答案，针对最难步骤挖空

用户于2026-10-24明确采用答案先行的挖空路线，并要求优先隐藏最难推理。新理论入口不再让作者自由选择一个问题、现求答案后压缩题面，而是先用独立调用从来源抽取已有结论和答案，再重建完整证明。来源抽取仍需后续独立证明审查，不能将模型输出当作已认证真值。

## 固定结果与完整证明

`known_result.txt`产生严格的ResultSelection：found必须带KnownResult，unavailable必须为空并说明来源缺口。结果记录来源ID、定位、已有结论、目标、答案、原始前提及引句。程序核对引用和来源；来源抽取的结构/证据修复最多三次调用。没有可用结论就终止该出题线，不能即兴造金标。

随后solution调用必须复制固定答案和design.target，保留原始前提，展开完整证明并选定最难的推理。独立蓝图judge验证来源确实已有该结果、全域/边界正确性和完整推导。它返回具体错误条目供修复。若固定来源结果本身不成立或无法被来源支持，使用known_result问题类型终止该线；不通过换答案掩盖原锚点错误。普通证明/题面质量修复最多初稿加两次修订，共三轮；这是与结果抽取分开的上限，所有调用均计费用。

同一谱系的加难、降难和内部修复均保留相同结果；完整题面更改后重审。新参数、新目标或不同答案须另开来源结果和谱系，不能复用原通过标记。锁定答案只防止漂移，不能证明它正确。

## 最难步骤的挖空记录

理论配置启用require_known_result与require_bottleneck_mask。DifficultyDesign中的mask包含：

| 字段 | 意义 |
|---|---|
| step_id | 必须是选定的bottleneck_step |
| proof_step_indices | 完整derivation中的1起始条目，不是紧凑推理图编号 |
| hardest_reason、alternative_steps | 为什么选这一推理，与其他步骤比较；属于待验证判断 |
| hidden_information | 要隐藏的引理、表示、变换、分支或参数范围，以及透露该推理的提示 |
| retained_information | 保留的原始观测、定义和约束 |
| recoverability | 从保留信息如何仍能恢复固定目标 |

程序拒绝空计划、错指瓶颈、重复/越界条目；不通过正则判断自然语言推导是否正确或泄露。

完整证明可写作A→B→C→D，若C是最难且必要的桥梁，题面给足A和目标D，隐藏C及相应解法提示，按需连同B一起隐藏。不能只把D换成空格，却将C的计算配方直接交给解题者。

## 两层judge与后续回测

第一层蓝图judge审完整参考证明，检查所选难点是否有根据、必要性和旁路。题面产生后，第二层独立调用bottleneck_audit核对实际文本，返回selection_supported、hidden、necessary、recoverable和not_answer_only五项pass/fail/uncertain。等价说法泄露也应退回；同一概念负担的不同合法证明不是旁路。未能解出只说明不确定，不能伪造缺条件反例。

任一项失败或不确定均阻止GLM，反馈带旧题、完整证明和全部挖空检查记录返回作者。接口/schema/映射失败单列，不当作题目错误。审查收据绑定题面、完整证明、固定结果、来源内容哈希、提示和模型配置；修改使旧收据失效。采样、恢复和导出都检查相应约束，不能只看作者声明或旧通过布尔值。

此外仍须综合审查、独立盲解、自洽、公式翻译与受限精确反代；这些步骤不是由mask审查替代。最后按原GLM5.2的600秒、无工具、4→16规则测难度。4/4优先进一步隐藏中间信息；0/16先查正确性，降难时优先缓解其他步骤。若固定结果下没有合适版本，保留失败，不宣称交付成功。单独揭示桥梁的easier_control可以用于比较，但尚未执行就不能算难度因果证据。

“最难”目前是作者与同系列独立上下文judge的选择，不是程序证明或客观难度排名。真实GLM作答和受控提示比较才可能支持它；新增门禁本身不证明产物更难。
