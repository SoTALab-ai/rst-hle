# 论证题的独立难度研究合同

`model-argument-study-v1`用于已经完整前置质检、要求推导或论证的冻结题面。它是独立研究入口，不修改官方HLE提示，不覆盖旧run，不将研究答卷写成生产`Trial`或导出为合格交付。原生产采样对`argument_or_witness_validation`的阻断保留。

先运行原科学质检和冻结verifier。新增两种对照：正确结论但缺少题目要求的实质论证、正确结论但有错误关键推理；另保留至少两个合法等价解。金标只作参考结果，结合完整推导和来源核对科学正确性，不作为必须独立完成证明的答卷加入对照或后审。独立oracle不看生成标签；论证审查仅看公开题面、输出清单和答卷，不看gold、作者方法、来源或对照标签。程序核对所有输出映射、oracle一致性和两类破坏的覆盖。对照未完成或存在争议，不购买GLM。

GLM仍只看原题，使用原模型、无工具、600秒墙钟和原输出格式，不设客户端输出token上限。每份答卷分别运行冻结HLE最终答案比对和独立论证审查。原HLE原样存档；结论匹配但论证确有错误/缺失计错，论证通过且HLE匹配才计对。论证uncertain、论证通过而HLE不匹配、接口/结构失败均单列未完成，不能计错。600秒解题超时保留deadline收据、无伪造答卷或judge。

首4次全对即结束，不加难、不补买；出现实际错答/解题deadline才补16次。1–8/16只标记需要后审，0/16需要科学复核，9–16/16偏易；本入口不自动承诺去重留存或生产交付。这里的正确率是模型论证评测研究结果，不能冒充原HLE分数或形式化证明。

状态以个人VM独立PG的CAS引用为准，本地JSON仅镜像。题面、gold、完整证明、模型、提示、来源或代码变化要求新run；解题回复先持久化，再判分，成功请求用原网关封印恢复。任何失败都留痕并计费。运行需使用`ArgumentStudy`，显式检查完整前置门槛后调用；通用生产采样/导出没有旁路。

论证对照生成器只接收题面、输出清单和完整参考推导，不接收金标说明，避免把省略论证的参考文字复制为“合法答卷”。对照仍须由独立oracle和不见参考推导的答卷审查验证，生成标签不提供通过资格。

入口为`scripts/evaluate_argument_study.py`，需提供独立运行ID、PG中已审候选ID及完整内容哈希、价格快照、冻结清单及其SHA256和输出目录。沿用`configs/library-dependency-masking.toml`的原模型与时限配置；启动前检查冻结文件、候选身份和无工具/600秒/无客户端token上限。运行报告分别列真实答卷、deadline计错、论证正确数、HLE匹配数、未知/在途费用及生产交付0。
