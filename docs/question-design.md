# 从已验证参考解反向构造题目

2026-10-25对53道首4/4题的[完整推导与旧答卷审计](validation/easy53-audit-2026-10-25.md)发现：隐藏步骤也可能过于常规，错误捷径的反例不等于排除了最短正确路线。后续提示先做正确短解挑战；蓝图明确认定目标偏浅时返回`target_depth`，终止该线而不让作者整包重写或换gold。profile已更新，旧冻结结果保持原样；新提示尚未通过真实新批次验证。

当前理论出题采用“来源已有结论与答案锁定 → 完整证明重建与复核 → 选定最难推理桥梁 → 挖空题面 → 独立验证 → 难度实测”。挖空针对完整证明中最难且必要的推理，而非只删掉最后的答案。理论出题沿用用户要求的激进隐藏策略，先偏难，再根据有效盲答结果校准。

2026-10-25用户最新口径放宽论文复现要求：新论文库试产可先提出由论文启发的自洽构造，锁定其答案/目标/模型前提，独立复核完整证明后出题。逐字引用与原文结论一致性改为溯源提示；题目正确性与难度规则不变。后文的严格来源结果模式保留给历史配置，差异见[来源口径](source-fidelity.md)。

2026-10-24新配置已将作者统一为gpt-6-luna，理论入口沿用high。先写完整答案及逐项推导，再由独立judge返回步骤编号、证据和修复要求；最多三轮质量对抗，通过后才另行生成题面。新增模式卡、推理依赖图及父题实际答卷反馈，指导必要技能连接与旧捷径失效。推理图不替代完整证明，也不保证难度。论文依据与验证方案见[固定模型下的难题构造](harder-question-design-2026-10-24.md)。这些修订不追溯替换已结束的100条冻结试产。

2026-10-24后续修订将前端收紧为独立的已有结论抽取调用；完整参考解、质量修复和难度改写均须保留其答案、目标和原始前提。最难步骤映射到完整证明的条目，由单独的题面挖空审查检查隐藏、必要性与可恢复性。详见[最难步骤挖空合同](bottleneck-masking.md)。旧冻结运行不回填新通过标记。

锁定前提优先保留原串。若作者改写文字，独立蓝图审查须逐条返回`assumption_correspondence`，绑定原始前提和实际参考解前提，并给出等价性证据；程序不靠模糊匹配或同义词表判等。缺映射、非等价、审查未通过或步骤覆盖不全仍拒绝。映射不抵消其他科学/瓶颈缺陷，亦不替题面补充条件。

蓝图阶段不能把整篇来源或完整参考解视为解题者可见的题面。旁路审查只能使用逆向构造和`retained_information`明确保留的信息；边界未定就指出具体不确定处，不能因为论文中存在另一种证明便认定题面泄露。最终以实际题面重新独立检查隐藏步骤与旁路。

锁定私有金标有时附带正确解释。后续提示在947c366澄清：新的金标优先简短，但旧金标须原串保留，不能要求作者删解释后又因锁定字段变化拒绝。解释本身不等于题面泄露或要求解题者复述证明；仍须核对解释的正确性、实际输出覆盖和推理旁路。程序对答案/目标改写的严格绑定保持，不能靠某次judge赞同就换金标。这个提示修订不覆盖25f83b9的在途续产；[真实蓝图诊断](validation/library20-gold-explanation-probe-2026-10-25.json)仅验证两次审查，原推导仍有难度设计缺陷，未宣称完整质检通过。

## 一个例子

假设参考解包含“识别隐含矩阵分块 → 推出可行参数域 → 选择物理解分支 → 求一个谱不变量”。题面可以只给原始观测、定义矩阵的关系和最终目标，不给分块技巧、参数区间、辅助恒等式和分支选择规则的推导结果。解题者需要自己发现这些结构。

参考解必须完整说明这些条件为什么成立；题面不必逐条直接告知。如果参数域本来是需要求出的量，就保留决定它的约束，而不直接给区间。出题阶段可以大胆尝试删减；删后不能唯一恢复目标或出现物理矛盾，就由独立质检拒绝/修复。错误前提或错误金标不作为难度收益。

题面生成与质检提示明确区分原始定义和推导条件，不再要求把参考解中所有必要条件直接写进题面。质检应先尝试由剩余约束推出隐去条件；认为信息不足时指出具体歧义或未建立的蕴涵，能构造两个合法实例而目标不同则给出反例。未能推出只算不确定，不自动证明题目有错。这项提示修订也晚于87a212b冻结，只适用于后续新运行。

隐藏计划还须与实际题面逐项对照：若design声称应自己发现某个引理、恒等式、变换、分支准则或参数范围，题面却直接提供它，综合审查的no_shortcut应退回并指出泄露步骤。原始观测与基本定义不受此条限制。这是提示层合同，不能仅凭字段存在宣称已成功隐藏；也尚未在新一批真实试产中验证。

金标由程序从参考蓝图绑定到最终bundle，题面生成不能另外决定答案。对齐模型若输出不同答案字段，保留原始响应与字段哈希，再绑定参考答案；独立盲求解仍必须确认题面确实对应这个答案，不能靠绑定掩盖题目目标漂移。此修正晚于87a212b冻结，不热替换100条试产快照；原外部提交bundle仍严格检查两个答案字段一致性。

## 各阶段的提示与产物

2026-10-25新增四类首题参考及依赖回溯：[挖空设计](bottleneck-masking.md)。从结果反求全部参数/结构、判分支、完整区域/边界和定理适用性都在目标锁定前选择；从完整证明回溯隐藏可恢复的推理桥梁，保留充分定义与必要前提。蓝图和题面挖空分别审查完整目标与实际可解性，不把类型标签视为难度证据。验算失败按[类别和责任阶段](consistency.md#失败归因与定向修复)定向反馈，不能因证书问题重新生成整套题目；进入verifier后仍冻结题面、golden和推导。

新论文库配置开启`use_locked_proof_draft=true`：作者输出完整推导和设计正文，输出schema不包含answer、design.target及锁定前提。程序从KnownResult绑定这些不可变输入，再由独立蓝图审查检查整份推导与实际golden。这样避免“要求复制原金标却又让模型缩写”的往返损耗，不允许覆盖作者提出的错误答案或用绑定代替正确性审查。额外前提必须是证明过的推论，不能静默缩小锁定模型。

前置检查完成后进入verifier即冻结题面、golden与完整推导。只修verifier和测试对照；发现上游缺陷终止当前版本并返回具体问题，不触发外层作者循环。历史可改题的verifier实验保持原快照和统计。

## 首题挖空与后续降难

首题的锁定模式优先隐藏最难推理及等价提示，可以隐藏其他可恢复的中间步骤、移除由保留条件推出的约束。不得更换固定目标、答案或原始前提。每次只明确改动一个主要推理负担，记录哪些条件删了、为什么预计仍可推出目标。不要通过添加很多容易漏答的子问降低通过率。

当前仅允许降难：首4次全对或完整9–16/16直接拒绝，不再加难。锁定模式降难优先补回前置或其他步骤的提示，保留所选最难推理供解题者恢复；若无法在固定结果下达到目标难度，记录该谱系未达标，另选来源结论开启新谱系。另行测试的easier_control可揭示关键引理，但不作为挖空版本交付。父题0/16时先排除错误金标、歧义和信息不足，再决定是否真正太难。

## 可验证性和材料边界

数学与理论物理优先选择有清楚模型、可定位证明/推导、有限特化和可反代答案的材料。顶刊是选材条件，不是难度保证。首次100条计划复用已核实的10篇论文、多种不同构造方向，按同论文相关样本解释；最终独立题数仍受语义及material_key去重限制。

来源保存全文，但当前模型输入仍受max_source_chars约束；不能把已抓全文写成模型已读全部证明。无通用形式化证明器，公式翻译对齐仍依赖模型；精确程序仅证明给定表达式的代入结果。纯证明题明确标注无算术覆盖，不能将它称作已程序证明。
