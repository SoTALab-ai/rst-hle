# 已有答卷的上下文抽取复核

物理 P02MASK 的第3号答卷在方框中保留了温度因子 Θ，但紧接着明确说明：若采用题面规定的去 Planck 因子约定，应删去 Θ。旧判分只认可方框，把这条适用的说明忽略，形成抽取误杀。官方 HLE 模板没有规定方框优先；本次保留官方 user 模板及其哈希，新增有版本与哈希的 system 抽取指引。完整请求协议因此发生变化，不能声称与官方完整会话逐字相同。

第9号答卷的系数是金标的 π/2 倍。因因子为正，它是一个较弱但仍成立的上界；推导中的归一化另有错误。题面只问 upper bound，而固定金标要求特定规范化界，可能存在目标口径歧义。它不能直接归为物理反例，也不能通过偷偷更换金标来接纳。

复核入口 `scripts/recheck_existing_answers.py` 在新 run 中先验证全部旧 solver 收据及600秒截止收据，只重判13份真实答卷，保留3次截止计错。网关在缓存与网络调用之前拒绝 solver 和 generator。科学复核与答案匹配分开记录；全部答卷（含旧判对的）和初始来源结果、完整金标推导一起进入后置对抗。质检仍有争议时不认证有效难度。

新快照使用 `configs/theory10-judge-context.toml` 和同名 plan。旧题面、金标、GLM答卷和历史判分不覆盖。新增请求、费用、未完成检查均单独统计。
