# 验收映射

需求原文为飞书《HLE四期需求》，通过飞书 CLI 于 2026-10-23 导出。原文只保存在本地；`configs/quotas.v3.json` 中的 `source_sha256` 可与本地快照核对。后续用户澄清优先于原文。

| 要求 | 实现 | 验证/范围 |
|---|---|---|
| 61 个采购子类、验收后共 2,000 道 | `configs/quotas.v3.json` | 原文 JSON 提取，断言 61 与 2000；配额逐类统计 |
| v3 分类 | 固定 category + subtopic 名称 | 沿用文档，不重分类；文档没有提供的 22 个零配额子类不自行编造 |
| 600 秒硬限时、无客户端 token 上限（用户后续变更） | Gateway deadline + 配置 | 覆盖重试等待，超时和截断均不判错；当前无工具模式 |
| GLM5.2 每题 16 次 | `Pipeline.sample` | 独立请求 ID；样本不完整或复用即失败 |
| gpt-6-luna medium judge（用户后续变更） | 模型配置 + 官方模板哈希 | 返回实际模型名不匹配即失败 |
| 只保留 1–8/16 | `evaluate` / 导出复查 | 0、1、8、9、16 边界测试 |
| 官方 HLE 判分 | 固定官方模板与字段 | gold 只给 judge；不以参考解推翻 gold；没有新增数值容差 |
| 完整纯文本、答案与依据 | 严格 schema + evidence/static + audit | 引句需存在于保存全文；模型复核不保证学科真值 |
| 批次内独立题 | 字符去重 + 全参考分批语义比对 + material_key / root 限制 | 语义 judge 仍有漏检风险；同谱系默认至多计一道 |
| 旧训练集、完整官方评测集去重 | 当前关闭 | 用户 2026-10-23 明确“先不用管”；导出 manifest 标注跳过 |
| 原文示例不计入交付 | 本地 120 道排除库 | 不进入生成 prompt；本地文件存在则自动用于去重 |
| 采样/判分可复核 | 请求响应 JSON、参数、实际模型名、模板哈希、16 次结果 | 数据默认不进公开 Git |

状态说明：`quality_seed` 为质量合格但可能太易/太难或采样未完成；`screened` 为试产筛选通过；`accepted` 为 production 模式机器质检通过并占用配额；`rejected` 为证据/题目质量/重复问题。`accepted` 不代表经过外部专家或官方 HLE 认证。

尚未完成：采购 2,000 道、跨学科正确性评估、旧题库排除、递归收益与真实单位成本验证。不要把测试样例的通过或论文中的任务成本当作本项目产能承诺。
